# Gemini API key: কোথায় পাবেন, কীভাবে বসাবেন

ProNotes-এর ✦ AI ভয়েস আর AI সহকারীর "Gemini দিয়ে চালান" চলে আপনার নিজের Gemini key দিয়ে। Google AI Studio-তে key ফ্রি; বাংলাদেশ থেকে ব্যবহার করা যায় (Google-এর সমর্থিত দেশের তালিকায় আছে)।

## ধাপ

1. `https://aistudio.google.com/apikey` খুলুন (ProNotes-এ: Settings → AI সহকারী → "Google AI Studio খুলুন ↗")। নিজের Google (Gmail) অ্যাকাউন্টে ঢুকুন।
2. প্রথমবার শর্তে রাজি হলে Google নিজেই একটা Google Cloud প্রজেক্ট আর একটা key বানিয়ে দেয়। না দিলে **Create API key** চাপুন।
3. key-এর পাশে **Unrestricted** লেখা থাকলে: **Add restrictions → Restrict to Gemini API only → Restrict key**। Google এখন বাধাহীন key নেয় না; অনেকদিন অব্যবহৃত বাধাহীন key "Blocked" হয়ে যায়।
4. key কপি করুন → ProNotes → Settings → AI সহকারী → ঘরে পেস্ট → **রাখুন** → **key যাচাই ও মডেল তালিকা**। "key ঠিক আছে" এলে হয়ে গেল।
5. প্রতিটা ডিভাইসে (iPad, ফোন, কম্পিউটার) আলাদা করে key দিতে হবে। key শুধু সেই ডিভাইসে থাকে, ব্যাকআপ ফাইলে যায় না।

## খরচ ও নিরাপত্তা

- **Billing চালু করবেন না।** তাহলে কোনো খরচ হয় না; শুধু প্রতিদিন/প্রতি মিনিটে কতবার চালানো যাবে তার সীমা থাকে। সীমা পার হলে ProNotes "সীমা শেষ" জানায়; পরে আবার চলে।
- ফ্রি স্তরে Google পাঠানো লেখা/অডিও নিজেদের সেবা উন্নত করতে ব্যবহার করতে পারে। তাই মক্কেলের নাম, ঠিকানা, দলিল নম্বর মুখে বলবেন না (লেখায় ProNotes এগুলো লুকিয়ে পাঠায়, অডিওতে পারে না)।
- key পাসওয়ার্ডের মতো: কাউকে দেবেন না, কোথাও পোস্ট করবেন না, Claude বা অন্য কাউকে চ্যাটে পাঠাবেন না। ফাঁস হলে AI Studio-তে নতুন key বানিয়ে ProNotes-এ বসান, পুরোনোটা মুছে দিন।
- Google সাধারণভাবে ওয়েব অ্যাপের ভেতরে key রাখতে নিষেধ করে, কারণ সেখানে সবার key এক থাকে। ProNotes-এ প্রত্যেকে নিজের key নিজের ডিভাইসে রাখেন, অ্যাপের কোডে কোনো key নেই — তাই এই ঝুঁকি নিজের key-এর মধ্যেই সীমিত।

## সমস্যা হলে

| বার্তা | কী করবেন |
|---|---|
| key ঠিক নেই | key আবার কপি করুন (শুরু/শেষের ফাঁকা বাদ), ধাপ ৩ করা আছে কি না দেখুন |
| সীমা শেষ | কিছুক্ষণ বা পরের দিন আবার চেষ্টা করুন |
| ইন্টারনেট নেই | সংযোগ দেখুন; AI ছাড়া বাকি ProNotes অফলাইনেও চলে |
| মাইকের অনুমতি নেই | iPhone/iPad: Settings → Safari → Microphone → Allow (হোম স্ক্রিনের অ্যাপে প্রথমবার জিজ্ঞেস করে) |
