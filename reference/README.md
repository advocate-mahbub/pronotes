# reference/

`bornona-pad-v8.html` is the last version of বর্ণনা প্যাড (Bornona Pad) built on claude.ai.
It is the behavioural yardstick for ProNotes. **Do not edit this file.**

`npm run golden` opens it in Chromium and records its behaviour into `tests/golden/*.json`
(every key of every layout, key sequences, Bijoy conversion of ~950 words, mixed copy/paste,
word suggestions). The unit tests check the new modules against those files.
